1 Structured extraction planned place-only pilot run

Split the text into labelled pieces, each copied word for word, so later checks run without another model call. Open decision: one combined prompt replacing the event-coding and place-extraction prompts.

1.1Per act
  • status: new / recalled / follow-up
  • trigger words
  • action type
  • actor, target
  • counts (killed, injured, arrested)
  • date as written
  • items seized or used
1.2Location pieces
  • site + type (village, town, locality, forest, camp, road, water)
  • police station
  • sub-district / block
  • district, state
  • "within" relations
  • location role: where it happened / where reported
1.3Semantic flags
  • abduction vs release / rescue
  • body recovered vs killing
  • surrender / arrest at a headquarters
  • several acts in one text (careful split)
  • several or relative dates
1.4Added after reading 50 random events new
  • non-event reasons: judicial, protest, threat, statement / denial, symbolic act, aggregate figures, later identification
  • outcome: successful / foiled / failed / defused
  • actions: cross-border shelling, sexual violence, beating / ransacking, lynching, extortion
  • actors: foreign forces, mobs, village defence committees, rebel vs rebel; attribution named / suspected / claimed / denied
  • counts with ranges and revisions; casualties outside India
  • time: act vs consequence date, date ranges, time of day
  • relations: near, between X and Y, direction from X, along a border
  • site types: market, religious site, school, hospital, office, security base, railway, mine, border sector / pillar
  • levels: sub-division, "area"
  • roles: victim's home or posting, hospital, operation base
  • several sites per act (serial blasts, raids); vague locations
1.5Added after a targeted batch of 50 new (Punjab/other, multi-incident, police station, 2020s, long texts)
  • text location overrides a wrongly assigned SATP district (Red Fort blast filed under Pulwama)
  • non-events: speeches with statistics, forensic / CBI / NIA findings, policy decisions, group splits
  • fragments with no act of their own: link to the incident's other parts
  • running totals and recaps of earlier days
  • decision needed: drones and smuggling at the border, old ordnance found, police-protester clashes, killings inside a group
  • acts outside India launched from India (raid into Myanmar), counts revised many times
  • disputed accounts (alleged fake encounters)
  • targets with roles: sarpanch, activist, informer, workers
  • relations with distances ("100 km from Ranchi")
  • roles: area of activity, where wanted, where curfew imposed
  • units: police district, police range / division, forest division, revenue division
  • sites: highway, toll plaza, bridge, mobile tower, border outpost, national park, river
  • dates: intervening night, "today", unknown killing date
pieces only, no model call

4 Location resolution pilot resolver v2

Match only the location pieces, inside the event's 2001 unit; map every candidate to a SHRID and 2001 census code.

4.1Gazetteers
sourcestatusrole
SHRID / SHRUGbuilttarget unit; village names, polygons, centroids; keys to 2001 and 2011 codes
OSM (Geofabrik)builtsettlements incl. hamlets, forests, roads, police; tehsil (level 6) polygons

LGD villagesdownloadedcurrent district and sub-district per village, 2001/2011 codes; 92.7% link to SHRID
LGD blocksmissingblock to village mapping for "X block" mentions
India Post pincodesmissingpost offices with coordinates; fourth gazetteer for small places
Police station listsmissingofficial station lists (data.gov.in, state police), Maoist states first
Google Mapslast resortonly for names the free sources cannot resolve or disagree on
4.2Matching rules
  • one normaliser (Latin-ASCII, type words stripped)
  • gazetteer chosen by place type
  • exact before fuzzy
  • fuzzy thresholds set from the hand checks
  • district names and aliases never count as places
4.3Police stations planned
  • never used as the event's village
  • seat village or town in the district
  • OSM police points
  • official lists
  • agreement of the three = confident
4.4Same-name places
  • use the "within" police station or block
  • uniqueness inside the narrowest named unit (LGD)
  • e.g. three villages called Rajpur in Chatra
4.5Check cascade planned  each candidate, coarse to fine; a failed check moves the event down one level and records why
  1. State point lies in the state the text names
  2. District point in the 2001 unit (1-2 km tolerance); mismatch also tested against the district named in the text
  3. Tehsil / block matched SHRID listed under the named sub-district in LGD (code lookup), else OSM level-6 polygon with tolerance
  4. Police station within a plausible distance of the named station, same tehsil where known
  5. SHRID polygon the polygon the point falls in carries the extracted name (or is its parent village)
  6. Uniqueness name unique inside the narrowest named unit; otherwise not a village
Fallback: SHRID village→ police-station area→ tehsil→ district
4.6Confidence tiers shrid (2+ sources share a SHRID) > high (2+ within 5 km) > single exact > police station / tehsil > single fuzzy > conflict > district only. Flags: city-wide SHRID, district-headquarters name, outside-unit match (possible SATP district error).
